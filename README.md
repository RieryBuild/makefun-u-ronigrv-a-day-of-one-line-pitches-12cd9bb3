One sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The entry

> That little app to keep your mum's recipes in one place? Just describe it in your own words to an AI agent on make.fun and it'll build the first version for you — no code, and if it's not right, you just walk away.

## How it works

`main.py` (Python 3.13, standard library only) writes that single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no secrets, no files read — the sentence lives as a string literal in `main.py`.

```sh
python3 main.py
```
